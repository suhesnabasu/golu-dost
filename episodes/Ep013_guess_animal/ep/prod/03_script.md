# Ep 13 script — बताओ कौन? / Guess the Animal

## Beat sheet
- 0–3 s HOOK: bush shakes hard, "म्याऊँ! म्याऊँ!", Golu turns to camera "बताओ, कौन?" (big "बताओ कौन? / Guess who?" card)
- 3–12 s RIDDLE 1: Bunny zooms in "शेर!" (wrong — boing) → whiskers peek → pause → "बिल्ली!" → Mithu "Cat! Cat!"
- 12–23 s RIDDLE 2: "मूँ… मूँ!" → Bunny "हाथी!" → Golu "हाथी तो मैं हूँ!" (laugh) → horns peek "सींग देखो…" → pause → "गाय!" → Mithu "Cow! Cow!"
- 23–31 s RIDDLE 3 (payoff): "क्वैक! क्वैक!" → Bunny stops herself, "मेरी बारी? बत्तख!" → Golu "हाँ! बत्तख!" → Mithu "Duck! Duck!"; a duck feather lands on Mithu's head (6th hat)
- 31–37 s RECAP: kids chorus "बिल्ली, गाय, बत्तख!" / "Cat, cow, duck!" with the 3 animals popping out together
- 37–40 s LOOP: "शाबाश!" → "कल फिर मिलेंगे!" → Mithu "Tomorrow! Tomorrow!" → bush shakes again (= frame 1)
